# Campus Marketplace System
ระบบตลาดนัดส่งต่อสิ่งของและหนังสือเรียนมือสองภายในมหาวิทยาลัย

## โครงสร้างโปรเจกต์
- `frontend/` - ส่วนแสดงผลผู้ใช้งาน (UI)
- `backend/` - ส่วนประมวลผลเซิร์ฟเวอร์ (API / Logic)
- `database/` - ไฟล์จัดเก็บและจัดการฐานข้อมูล
- `docs/` - เอกสารประกอบโครงงาน
- `tests/` - ชุดทดสอบระบบ

## สมาชิกในทีมและการแบ่งงาน
1. นางสาวโสรญา สวรรค์งาม - Project Manager / Product Owner
2. นางสาวเกสรา ชำนิเขตกิจ - UI/UX Designer & System Analyst
3. นายวรชิต คำอินทา - Full-Stack Developer (Lead Dev)
4. นายปุรเชษฐ์ ศิริเขตรกิจ - DevOps & QA Engineer
